# Backend

See the [root setup guide](../README.md) for installation, migrations, tests and local services.

Run commands with `uv run --directory backend ...` from the repository root. Configuration is read from process environment variables or `backend/.env` when executing there. Missing database configuration or a JWT secret shorter than 32 characters fails startup.

Default inference uses local Ollama (`all-minilm` embeddings, `qwen2.5:3b` chat). For a SentenceTransformers backend, install `--extra local-embeddings`, set `EMBEDDING_BACKEND=sentence_transformers`, `EMBEDDING_MODEL=sentence-transformers/all-MiniLM-L6-v2` and `EMBEDDING_DIMENSION=384`. Model loading is lazy, on first indexing/query use. Do not mix or silently reuse embeddings generated by a different model.
